# ColorPrism 项目文档

## 目录结构

```
doc/
├── 01-overview/          # 项目总览 - 整体架构、核心理念
├── 02-story-creation/    # 故事创意 - 故事生成、创意构思
├── 03-content-creation/  # 内容创作 - 文本、图像、视频生成
├── 04-material-management/ # 素材管理 - 素材收集、组织、存储
├── 05-implementation/    # 实现创意 - 最终输出、渲染、发布
├── 06-agents/            # Agent 系统 - 故事Agent、创作Agent
└── 07-mcp-tools/         # MCP 工具 - 外部工具集成
```

## 核心流程

1. **故事创意** → 2. **内容创作** → 3. **素材管理** → 4. **实现创意**

## 关键角色

- **用户** - 提供创意方向
- **故事Agent** - 辅助故事创作
- **内容Agent** - 生成文本、图像、视频
- **MCP Tools** - 外部工具集成
